# Hana Bot 🌸

Hana Botシリーズの公式ホームページです。Next.jsで構築しています。

## 開発環境

- Node.js 20.9以上

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## ビルド

```bash
npm run build
npm run start
```

Hana認証・HanaTicket・Hana管理の紹介と、アニメーション付きのレスポンシブなランディングページを含みます。各ボットの招待URLは、準備ができたら追加してください。
